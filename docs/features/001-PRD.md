# PRD 001: Bootstrap do Módulo `mod_videoplayer` & Ingestão Direta em Storage

**Objetivo:** Criar a estrutura base do plugin do tipo atividade/recurso (`public/mod/videoplayer`) no repositório do Moodle, registrar os esquemas de dados, configurar o provedor de Object Storage e implementar o fluxo de upload direto do cliente para o bucket de ingestão (*Presigned URL*), sem tráfego de mídia no servidor PHP.

---

### 1. Pré-Requisitos e Setup de Infraestrutura

Antes de iniciar a escrita do código PHP, as seguintes variáveis e recursos externos devem ser provisionados:

* **Bucket de Ingestão (`media-bucket`)**: Bucket MinIO local, compatível com S3, no desenvolvimento e bucket S3 em produção. Ambos devem ser configurados com política de **CORS** para aceitar requisições `PUT` originadas do domínio do Moodle:
```json
[
  {
    "AllowedHeaders": ["*"],
    "AllowedMethods": ["PUT", "GET"],
    "AllowedOrigins": ["https://moodle.local", "http://localhost:8080"],
    "ExposeHeaders": ["ETag"]
  }
]

```


* **Credenciais de Acesso**: Chaves com permissão restrita de escrita no bucket de ingestão (`PutObject`) declaradas no `config.php` do Moodle ou nas configurações administrativas do plugin (`settings.php`):
```php
$CFG->videoplayer_s3_endpoint = 'http://minio:9000'; // ou https://s3.amazonaws.com
$CFG->videoplayer_s3_key      = 'INGEST_KEY';
$CFG->videoplayer_s3_secret   = 'INGEST_SECRET';
$CFG->videoplayer_s3_bucket   = 'moodle-raw-videos';
$CFG->videoplayer_s3_region   = 'us-east-1';

```

#### Passo 3.4: Wrapper do Storage Client & Gerador de URL Pré-assinada

O cliente usa a API S3 para MinIO no desenvolvimento e S3 em produção. A Feature 001 gera apenas a URL de ingestão e grava o estado `PENDING`; fila, FFmpeg, webhook e atualização para `READY` pertencem à Feature 002.

* **`classes/storage_client.php`**: Abstrai o SDK (AWS SDK / S3 Client):


```php
<?php
namespace mod_videoplayer;
defined('MOODLE_INTERNAL') || die();

use Aws\S3\S3Client;

class storage_client {
    public static function get_client(): S3Client {
        global $CFG;
        return new S3Client([
            'version' => 'latest',
            'region'  => $CFG->videoplayer_s3_region ?? 'us-east-1',
            'endpoint' => $CFG->videoplayer_s3_endpoint ?? null,
            'use_path_style_endpoint' => true,
            'credentials' => [
                'key'    => $CFG->videoplayer_s3_key,
                'secret' => $CFG->videoplayer_s3_secret,
            ],
        ]);
    }

    public static function generate_presigned_put_url(string $filename, string $filetype): array {
        global $CFG;
        $s3 = self::get_client();
        $unique_key = 'raw/' . uniqid() . '_' . clean_param($filename, PARAM_FILE);

        $cmd = $s3->getCommand('PutObject', [
            'Bucket'      => $CFG->videoplayer_s3_bucket,
            'Key'         => $unique_key,
            'ContentType' => $filetype,
        ]);

        $request = $s3->createPresignedRequest($cmd, '+30 minutes');
        return [
            'upload_url' => (string)$request->getUri(),
            'storage_key' => $unique_key
        ];
    }
}

```

#### Passo 3.6: Formulário com Direct Upload Assíncrono (`mod_form.php` e AMD JS)

1. **`mod_form.php`**: Define o campo de seleção de arquivo e o campo oculto `storage_key` preenchido após o upload direto:


```php
<?php
defined('MOODLE_INTERNAL') || die();
require_once($CFG->dirroot.'/course/moodleform_mod.php');

class mod_videoplayer_mod_form extends moodleform_mod {
    public function definition() {
        global $PAGE;
        $mform = $this->_form;

        $mform->addElement('text', 'name', get_string('name'), ['size' => '64']);
        $mform->setType('name', PARAM_TEXT);
        $mform->addRule('name', null, 'required', null, 'client');

        $this->standard_intro_elements();

        // Input de arquivo puro (não usa a File API local)
        $mform->addElement('filepicker', 'video_file_input', get_string('videofile', 'mod_videoplayer'), null, [
            'accepted_types' => ['.mp4', '.mov', '.mkv']
        ]);

        // Armazena a chave gerada após o upload direto via JS
        $mform->addElement('hidden', 'storage_key');
        $mform->setType('storage_key', PARAM_RAW);

        $this->standard_coursemodule_elements();
        $this->add_action_buttons();

        // Carrega o módulo JS de upload
        $PAGE->requires->js_call_amd('mod_videoplayer/direct_upload', 'init');
    }
}

```


2. **`amd/src/direct_upload.js`**: Intercepta o arquivo, pede a *Presigned URL* via AJAX do Moodle e faz o `fetch(url, { method: 'PUT', body: file })` direto para o bucket. Ao finalizar o envio com status 200, injeta a `storage_key` no campo oculto `storage_key` do formulário antes do submit.



#### Passo 3.7: Ciclo de Vida do Módulo (`lib.php`)

Grava o registro com status `PENDING` ao salvar o formulário:

```php
<?php
defined('MOODLE_INTERNAL') || die();

function videoplayer_supports($feature) {
    switch($feature) {
        case FEATURE_MOD_ARCHETYPE:
            return MOD_ARCHETYPE_RESOURCE;
        case FEATURE_SHOW_DESCRIPTION:
            return true;
        default:
            return null;
    }
}

function videoplayer_add_instance($data, $mform = null) {
    global $DB;
    $data->timemodified = time();
    $data->status = 'PENDING';
    return $DB->insert_record('videoplayer', $data);
}

function videoplayer_update_instance($data, $mform = null) {
    global $DB;
    $data->timemodified = time();
    $data->id = $data->instance;
    return $DB->update_record('videoplayer', $data);
}

function videoplayer_delete_instance($id) {
    global $DB;
    return $DB->delete_records('videoplayer', ['id' => $id]);
}

```

### 4. Roteiro de Validação do PRD 001

1. **Instalação**: Acessar `[http://moodle.local/admin/index.php](http://moodle.local/admin/index.php)`. O Moodle deve identificar o componente `mod_videoplayer` e criar a tabela `mdl_videoplayer` via XMLDB.


2. **Criação da Atividade**: Entrar em um curso como professor, ativar edição e selecionar "Vídeo OTT".


3. **Validação de Isolamento de I/O**:
* Selecionar um vídeo de 500 MB e submeter o formulário.


* Monitorar o tráfego de rede e o console do navegador: o payload binário deve trafegar diretamente para o endpoint do Storage (`PUT http://minio:9000/moodle-raw-videos/...`).


* O Moodle deve receber apenas a requisição POST final contendo `storage_key` (payload de poucos bytes).




4. **Verificação no Banco**:
```sql
SELECT id, course, name, storage_key, manifest_url, status FROM mdl_videoplayer;

```


O registro deve conter a chave preenchida e `status = 'PENDING'`.
