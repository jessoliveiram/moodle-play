# PRD 03: Telemetria do Player, Analytics & Conclusão de Curso

**Objetivo:** Rastrear o comportamento de consumo do aluno segundo a segundo, registrar métricas de retenção e alimentar tanto a API nativa de conclusão do Moodle quanto o painel de métricas do professor.

### Requisitos Funcionais (RF)

* **RF3.1 - Telemetria em Tempo Real (Beacon)**: O frontend emite pings periódicos a cada 10 segundos e em eventos críticos (`pause`, `seeked`, `ended`) chamando a External API `mod_videoplayer_save_progress`.
* **RF3.2 - Armazenamento de Progresso**: Persistir a posição atual, maior tempo alcançado (*furthest second reached*), tempo total assistido e status de conclusão por aluno.
* **RF3.3 - Integração com Completion API**: Quando o percentual assistido atingir o limiar estipulado nas configurações da atividade (ex: $\ge 80\%$), marcar automaticamente o módulo como concluído para o estudante via `completion_info`.
* **RF3.4 - Dashboard do Professor**: Na visualização do professor (`view.php`), exibir uma tabela contendo:
* Nome e e-mail do aluno;
* Progresso percentual e tempo total assistido;
* Indicador de conclusão (Sim/Não);
* Data e hora do último acesso.



### Modelo de Dados (`db/install.xml`)

| Tabela | Coluna | Tipo | Descrição |
| --- | --- | --- | --- |
| `mdl_videoplayer_tracking` | `id` | INT(10) PK | Identificador único |
|  | `videoplayerid` | INT(10) FK | Referência para `mdl_videoplayer.id` |
|  | `userid` | INT(10) FK | Referência para `mdl_user.id` |
|  | `lastposition` | INT(10) | Posição onde o player parou (em segundos) |
|  | `furthestposition` | INT(10) | Ponto mais distante assistido (evita fraude por seek) |
|  | `totaltime` | INT(10) | Tempo acumulado de reprodução (em segundos) |
|  | `percentcomplete` | INT(3) | Porcentagem calculada ($0$ a $100$) |
|  | `completed` | INT(1) | Flag booleana de conclusão ($0$ ou $1$) |
|  | `timemodified` | INT(10) | Timestamp da última atualização |

### Critérios de Aceite

* O avanço forçado da barra de progresso (*seek*) até o final do vídeo sem o tempo real correspondente não deve computar os 100% de conclusão.
* Professores e administradores conseguem exportar o relatório de engajamento da turma.
